Outline-Shader: Pixel-Inspektor

Jedes Kästchen ist ein Pixel. Fahr mit der Maus (oder dem Finger) darüber, um zu sehen, was der Shader für genau diesen Pixel tut.

schwarzer Rahmen: untersuchter Pixel grün: Figur gesehen rot: nichts gesehen
Shader-Code (HLSL, Custom-Node) 
float2 ViewportUV = GetDefaultSceneTextureUV(Parameters, 14);
float3 Scene = SceneTextureLookup(ViewportUV, 14, false).rgb;
float Center = SceneTextureLookup(ViewportUV, 25, false).r;

// Inside a marked unit: no outline here, skip the ring
if (Center > 0.1)
{
    return Scene;
}

// Size of one pixel in UV space
float2 PixelStep = View.ViewSizeAndInvSize.zw * Width;

// Strongest stencil value found on a ring around this pixel
float Neighbor = 0.0;
for (int i = 0; i < 8; i++)
{
    float Angle = 6.2831853 * i / 8.0;
    float2 Offset = float2(cos(Angle), sin(Angle)) * PixelStep;
    Neighbor = max(Neighbor, SceneTextureLookup(ViewportUV + Offset, 25, false).r);
}

// Edge: pixel itself is unmarked, a neighbour is marked
float Edge = saturate(Neighbor) * (1.0 - saturate(Center));

// Stencil 2 (Selected) wins over 1 (Hovered)
float3 OutlineColor = (Neighbor > 1.5) ? SelectColor : HoverColor;

return lerp(Scene, OutlineColor, Edge);
